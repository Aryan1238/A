01 / The Placement Challenge

Why University Placement Candidates Struggle

75%

The ATS "Black Hole"

Over 75% of student resumes are eliminated by Automated Applicant Tracking Systems (ATS) due to missing keywords, poor formatting, or role misalignment before human review.

0x

Zero Realistic Viva Practice

Students face technical interview anxiety because traditional placement training provides theoretical lecture slides instead of interactive, multi-turn technical interview rounds.

$$$

Commercial Gatekeeping

Existing mock interview platforms (LeetCode Premium, Interviewing.io) cost $30–$150/month, making quality AI assessment inaccessible to ordinary college candidates.

🎯 The Goal: Provide an accessible, free, production-grade AI platform that diagnoses resumes and simulates authentic technical interviews with instant, personalized feedback.
02 / The PrepPilot Solution

Dual-Core AI Placement Preparation Platform

01

AI Resume ATS Auditor

Instant PDF Analysis
  • ✓ In-Memory PDF Parsing: Extracts raw text directly from buffers with zero disk storage leaks.
  • ✓ ATS Match Score (0–100): Evaluates keyword overlap, technical competency, and relevance against target JD.
  • ✓ Actionable Critique: Delivers matched/missing keywords, section feedback, and 5 concrete improvement steps.
02

AI Mock Interview Coach

5-Question Technical Rounds
  • ✓ Role & Difficulty Tiers: Frontend, Backend, Full Stack, Data Science across Beginner, Intermediate, and Advanced.
  • ✓ Per-Answer AI Grading: Evaluates answers out of 10 with constructive strengths & weaknesses critique.
  • ✓ Ideal Model Answers: Shows industry-standard model answers for instant learning and reinforcement.
Both engines persist analyses to MongoDB Atlas and compute real-time visual progress on user dashboards.

04 / Deep Dive — Feature 1

AI Resume ATS Analyzer & PDF Exporter

Analysis Pipeline

1. In-Memory Upload: Multer intercepts candidate PDF in memory buffer (5MB limit, PDF-only mime filter).
2. Text Extraction: `pdf-parse` extracts clean text; sanitizes non-ASCII characters & line breaks.
3. Gemini Evaluation: Sends structured prompt comparing resume text vs. job description.

Generated Output Schema

ATS Match Score 0 – 100% Score
Keyword Gap Matrix Matched / Missing
Section Feedback Summary, Skills, Experience, Education
Improvement Steps 5 Concrete Actionable Items
Report Export 1-Click PDF Generation (`html2pdf`)
💡 Viva Highlight: Gemini prompt enforces strict RFC8259 JSON output with custom parsing fallback logic. POST /api/analysis/upload

06 / Security & Data Integrity

Database Schemas & Production Security

🗄️ MongoDB Schemas & Relations

User: name, email (unique index), passwordHash (bcrypt), timestamps.
Analysis: user (ObjectId ref), atsScore, matchedKeywords, missingKeywords, suggestions.
Interview: user (ObjectId ref), role, difficulty, questions[], averageScore.

🛡️ Security & Defensive Measures

Password Hashing: `bcryptjs` pre-save hook with 10 salt rounds. Plaintext never saved.
JWT Verification: Strict Bearer token authentication middleware guards private routes.
Rate Limiting: `express-rate-limit` prevents API brute-forcing and Gemini cost spikes.
🔐 Secret Isolation: All sensitive credentials (`MONGODB_URI`, `JWT_SECRET`, `GEMINI_API_KEY`) managed via environment variables and never exposed to the client.
